# Jarvis Atelier

Construimos software a medida para clientes y desarrollamos productos propios. Equipo chico, foco grande, decisiones técnicas con fundamento.

## Qué hacemos

- **Desarrollo a medida** — aplicaciones web full-stack para empresas que necesitan algo que no compran de góndola.
- **Productos propios** — herramientas SaaS y plataformas verticales con IA integrada.
- **Integraciones** — pasarelas de pago, sistemas externos, APIs de terceros, automatizaciones de negocio.
- **Consultoría técnica** — auditorías de arquitectura, planes de migración, code reviews para equipos que quieren crecer bien.

## Stack

**Frontend**
- React + TypeScript con Vite
- Diseño basado en componentes, atomic design cuando escala
- State management según el caso (no metemos Redux para guardar un booleano)

**Backend**
- NestJS sobre Node.js
- Prisma como ORM
- PostgreSQL como base de datos principal
- Arquitectura por módulos, separación clara de capas

**IA**
- Integraciones con LLMs en productos donde aporta valor real (no IA por marketing)
- RAG, agentes, automatizaciones, generación asistida

**Servicios e infra**
- **Pagos:** Mercado Pago (suscripciones, checkouts, splits)
- **Media:** Cloudinary (imágenes, video, transformaciones)
- **Deploy:** Railway y Render
- **Observabilidad:** logs estructurados, monitoreo de errores, métricas

## Cómo trabajamos

- **Conceptos antes que código.** Entender el problema antes de tocar el editor.
- **Tests reales.** Unit, integration y e2e donde corresponde. Coverage como herramienta, no como objetivo.
- **PRs revisados.** Nada va a `main` sin pasar por revisión humana.
- **Documentación viva.** README, ADRs y specs que reflejan lo que hay, no lo que había.
- **Iteración corta.** Releases frecuentes, feedback rápido, mejora continua.

## Tipos de proyectos

- Plataformas SaaS multi-tenant
- Dashboards administrativos y CRMs internos
- Marketplaces y e-commerce con pasarelas de pago
- Bots y agentes conversacionales con IA
- Backoffices, paneles y herramientas internas
- Integraciones B2B y migraciones de sistemas legacy
